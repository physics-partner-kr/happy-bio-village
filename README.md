> 우리는 자연의 숨결을 에너지로 바꾸고, 버려지는 쓰레기까지 자원으로 재활용하며,
> 지구와 함께 호흡하는 마을을 만들겠습니다.

## 보기

`index.html` 파일 하나로 열립니다. 작품 이미지가 파일 안에 들어 있어서 다른 파일이 필요 없습니다.

- **왼쪽, 학생 작품:** 휠이나 ↑↓ 키로 한 장면씩 넘깁니다. 장면마다 카드 문장을 구절별로 읽어 주고, 그 구절에 맞춰 그림이 움직입니다. 다 읽은 카드를 누르면 다시 볼 수 있습니다.
- **오른쪽, 공모전 안내:** ←→ 키, 탭, 화살표로 일정 · 코칭 · 시상 · 바로가기 페이지를 넘깁니다. 코칭과 본선 카운트다운은 항상 위에 보입니다.
